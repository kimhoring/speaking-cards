# 3초 만능문장

영어 말하기 문장 암기 앱 (개인 학습용).

## 문장 추가·수정
`src/cards.txt` 만 고쳐 올리면 됩니다. 몇 분 뒤 앱을 켜면 알아서 새 내용으로 바뀝니다.

- 단원: `# 아이디|PART n|단원 이름`
- 문장: `핵심 표현|뜻|한국어 문장|영어 문장`
- 영어 문장을 바꾸면 그 문장의 진도는 새로 시작합니다. 진도를 이으려면 `src/app.html` 의 `ALIAS` 에 옛 번호를 적습니다.

## 파트 5 주제 추가
`src/part5.txt` 에 같은 모양으로 덧붙입니다. 한 주제는 `#` 제목, `Q` 질문, `1`~`6` 단계, `K` 핵심 표현입니다.

- 단계: `번호|한국어 문장|영어 / 덩어리 / 로 / 끊기|같은 순서의 / 한국어 / 덩어리`
- 영어와 한국어 덩어리 수가 같아야 하고, 핵심 표현은 답안에 실제로 나와야 합니다. 어긋나면 배포가 멈춥니다.

## 구성
- `src/` 내용과 화면 → 웹 + 앱 내부 업데이트 (`web.yml`)
- `android/` 앱 껍데기 → APK (`apk.yml`, 가상 휴대폰 시험을 통과해야 배포)
